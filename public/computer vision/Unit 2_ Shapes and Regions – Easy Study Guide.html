SESSION 1

Binary Shape Analysis

What is a binary image?

An image with only two pixel values: 1 = object (white, foreground) and 0 = background (black). Rule: B(x,y)=1 if the pixel belongs to the object, else 0.

Think of a black-and-white stamp: ink where the object is, blank elsewhere. Shape analysis = measuring that stamp.

Why bother? Boundaries and shape measurements become easy to compute. Used in tumor detection, industrial inspection, OCR (reading text) and remote sensing (finding roads/buildings).

Workflow (6 steps)

1 Acquire image→2 Remove noise→3 Threshold→4 Find objects→5 Extract features→6 Classify
  • Acquire: camera/sensor takes the picture.
  • Preprocess: Gaussian or median filter removes noise (random specks).
  • Threshold: pixel > T becomes 1, else 0 (turns grey picture into black/white).
  • Object detection: find connected components (groups of touching pixels).
  • Features: measure geometry (area, perimeter…).
  • Classify: machine learning decides "what is it?".

Two ways to represent a shape

Moment features: numbers describing how the pixels are spread out. Boundary features: boundary length, curvature, Fourier descriptors (outline as waves).

Square 10×10: A=100, P=40 → circularity = 4π·100/1600 ≈ 0.79. A circle gives 1.0. So the square is "less round".

Algorithm: read image → find connected components → extract boundaries → compute area/centroid → compute perimeter → compute moments → build a feature vector (a list of numbers) for classification.

Advantages: simple, fast, easy features.

Limits: sensitive to noise; loses colour/texture; complex shapes need advanced descriptors.

Give every group of connected 1-pixels its own number. Count of labels = count of objects.

Size Filtering, Distance and Skeletons

Size filtering (throw away specks)

Big blobs = real objects. Tiny blobs = dust/noise. Count pixels in each blob and delete the small ones.

Steps: label objects (BFS, DFS or CCL) → measure area → set threshold T → remove if Area < T (optionally also remove if above a maximum) → output filtered image. Rule: Area < T → irrelevant, Area ≥ T → relevant.

ComponentAreaT = 50

Relevant: cells, coins, characters, fruits (large, meaningful shapes). Irrelevant: noise pixels, dust, segmentation errors (tiny, random). Opening can also remove tiny particles. Cell example: remove blobs under 20 pixels.

Skeletonization and thinning

Skeleton = peel the shape down to a 1-pixel-wide centre line, without breaking it or changing how many pieces/holes it has.

Uses: shape representation, length/width/orientation, fingerprint & character recognition, matching. Rules: keep connectivity, keep overall shape/topology.

Medial Axis Transform (MAT): medial axis = points inside the object that have at least two closest boundary points. MAT also stores each point's distance (radius) to the boundary. Skeleton = plain black/white image; MAT = grey image where brightness = distance.

Two ways to get it: (1) Thinning – repeatedly erode boundary pixels (keeping line ends) until nothing more can go; (2) Distance transform + ridge extraction. Also: Voronoi-based skeleton.

Binary shape→Clean (median/opening, threshold)→Distance transform→Ridge (local maxima)→Skeleton→Prune/smooth
  • Distance transform: each object pixel gets its distance to the nearest background; edges small (1), centre large.
  • Ridge extraction: keep peak values = farthest from boundary = centre line.
  • Post-processing: pruning removes tiny false branches; smoothing cleans the line.
A rectangle's skeleton: a horizontal centre line with a "Y" fork at each end (the diagonal lines to the corners).

Boundary Tracking

Goal: walk around an object's edge and record the pixels in order. Generic recipe: find a start pixel (top-left object pixel) → set a direction → search neighbours (4 or 8) → record boundary pixel → repeat until back at the start.

Boundary coordinates

The boundary as an ordered list (x1,y1),(x2,y2),…,(xn,yn) (row and column positions). Steps: acquire → preprocess (median/Gaussian, threshold) → extract boundary → track it.

A boundary pixel = an object pixel that has at least one background neighbour.

Morphological boundary extraction: B = A − (A ⊖ S) → take the object, erode it, subtract: only the outer ring is left.

Ways to represent the boundary

  • Chain code: directions as numbers – compact, good for matching.
  • Polygon approximation: replace the boundary with straight line segments – fewer points.
  • Signature: turn the outline into a 1D graph r(θ) = distance from centroid at each angle – easy to compare.

Features from coordinates: perimeter P=Σ dist(pi,pi+1), area (pixels inside), circularity 4πA/P², curvature (how sharply the edge bends).

OCR: scan → binary → trace each letter's boundary → features tell O (round), S (curvy), L (straight edges). Advantages: less computation, keeps shape info, good for comparison. Uses: OCR, medical, fingerprint, inspection, self-driving.
SESSION 5

Active Contours ("Snakes")

Draw a loose rubber loop around an object. The loop shrinks and wiggles until it hugs the object's edge. It "wants" to be smooth (internal force) and "wants" to sit on edges (external force).

It minimises energy: E_snake = E_internal + E_external (sometimes + E_constraint).

Steps

  1. Initialise a rough circle/ellipse near the object (need not be exact).
  2. Edges via gradients: |∇I| = √(Ix² + Iy²) (big intensity change = edge). Tools: Sobel, Prewitt, Canny.
  3. Internal forces: elastic (keeps points close) + bending/rigidity (prevents sharp kinks) → smooth curve.
  4. External forces: from gradients, edge maps, intensity changes → pull the curve to strong edges.
  5. Iterate: repeat update many times.
  6. Stop when contour is stable, energy is minimum, or max iterations reached.

Pros: accurate, handles irregular shapes, smooth result, OK with noise, great for medical images.

Cons: sensitive to starting position, fails on weak edges, slow, can get stuck in local minima.

Uses: tumor boundaries (MRI/CT; measure size, shape, growth), face contours, tracking in video, shape analysis, road boundaries.

Shape recognition

Identify an object from its geometry – useful even when colour/texture is poor. Techniques: template matching (compare with stored shapes), feature-based, statistical classification (SVM, k-NN), contour-based.

Image→Binary/segment→Features→Feature vector→Compare with models→Classify→Output class

Classifiers: k-NN (look at nearest similar examples), SVM (best dividing line between classes), Decision tree (if-then rules), Neural network (learns complex patterns).

Corners: 0 → circle, 3 → triangle, 4 → rectangle. Apps: traffic signs (stop = octagon, warning = triangle), tumors, defective products, handwriting.
SESSION 7

Handling Occlusion

Occlusion = something is blocking part of the object, like a person standing in front of a building. The front object is foreground, the hidden one is background.

It happens because a 3D scene is flattened to 2D. Less visible information makes detection, tracking, face recognition and scene understanding harder; the system may lose or misidentify the object.

  • Tracking: a pedestrian walks behind a car → system loses them, or counts two people.
  • Face recognition: masks, sunglasses, hats hide nose/eyes/mouth.
  • Augmented reality: virtual items must appear correctly in front of or behind real ones.

SESSION 8

Boundary Descriptors

Numbers or codes that describe an object using only its outline. Less computation, still keeps the important shape. Boundary comes from edge detection or boundary tracking.

Chain code

Record each move from one boundary pixel to the next as a direction number. 4-directional: 0 right, 1 up, 2 left, 3 down. 8-directional adds diagonals.

Boundary 0 0 6 6 4 4 2 2 = right, right, down, down, left, left, up, up → a square. Great for storing and comparing shapes.

Shape number

Take the first difference of a chain code (how much the direction changes each step). Because it records turns, not absolute directions, it stays the same if the shape rotates. Example: chain 0 0 2 2 4 4 6 6 → difference 0 2 0 2 0 2.

Other descriptors

  • Fourier descriptors: boundary coordinates → Fourier Transform. Low frequencies = general shape; high frequencies = fine details. Invariant to translation, rotation, scale (when normalised).
  • Polygonal approximation: straight line pieces; fewer points, same structure.
  • Curvature: how sharply the boundary turns; finds corners and bends.
  • Contour length (perimeter): separates shapes with equal area but different outlines.
  • Boundary diameter: largest distance between two boundary points; gives size and orientation.
Circle: smooth, low curvature. Square: 4 corners, equal sides. Triangle: 3 corners. Uses: object & character recognition, organs in medical images, defect detection, robotics.

Region Descriptors

Describe an object using all pixels inside it: size, orientation, symmetry, intensity spread. First segment the object (grayscale → denoise → threshold).

DescriptorFormulaIn simple words
AreaΣx Σy f(x,y) (f=1 object, 0 background)Count the object pixels = size
Centroidxc=(1/A)Σx, yc=(1/A)ΣyAverage position = balance point (tracking, alignment)
Orientationθ = ½·tan⁻¹(2μ11 / (μ20 − μ02))Tilt angle of the long axis
EccentricityE = √(1 − b²/a²)0 = circle, near 1 = long and thin (a = major, b = minor axis)
CompactnessC = 4πA / P²1 = perfect circle, lower = irregular
MomentsRaw Mpq=ΣΣ x^p y^q f(x,y); central μpq=ΣΣ (x−xc)^p (y−yc)^q f(x,y)Statistics of how pixels are spread; give area, centroid, orientation
Moments: M00 = area; M10/M00 and M01/M00 = centroid. Central moments subtract the centroid so they don't change when the object moves. Hu moments (built from them) are invariant to translation, rotation and scale.
Centroid of a 3×3 square at x=1..3, y=1..3: average x = 2, average y = 2 → centroid (2,2), the exact middle.

Classifying objects

Feed the features to KNN, SVM, decision tree or neural network. Compactness ≈ 1 and eccentricity ≈ 0 → circular object (coin). High eccentricity → elongated (leaf).
